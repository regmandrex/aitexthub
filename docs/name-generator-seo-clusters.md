## STEP 2: TOOL DEFINITION (SUMMARY)

Each name generator follows:
- **Tool name:** [Theme] Name Generator
- **Core purpose:** Generate themed names (culture, franchise, or use case).
- **Inputs:** Optional theme/keywords; count; sometimes gender or style.
- **Processing:** Rule-based or seeded random from curated word lists.
- **Output:** List of names (with optional meaning/culture label).
- **Schema:** SoftwareApplication / WebApplication.
- **Conversion:** Copy, regenerate; no sign-up.

Cannibalization prevention: one URL per cluster; semantic variations in H2/H3 and body; no duplicate intent pages.
